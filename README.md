# TECATEX Aerospace - Cyber-Tech Design Package (V2)

## 📁 Estructura del Paquete
- `index.html`: Aplicación web completa, interactiva y responsiva estilo Y2K / SaaS Monocromático (B&W).
- `README.md`: Instrucciones de uso y documentación de arquitectura visual.

## 🚀 Características Implementadas:
1. **Branding TECATEX Aerospace:** Integrado en todos los encabezados, insignias y estructura de interfaz.
2. **Estilo 100% Monocromático (Blanco y Negro):** Gráficos limpios, de alta definición y contraste preciso sin neones.
3. **Globo 3D Wireframe Interactivo (Three.js):** 
   - Manipulación de rotación por arrastre con mouse.
   - Alternador de densidad de malla.
   - Control de velocidad orbital.
4. **Módulo Analógico KASSETA C90:**
   - Reproductor con carretes en rotación animada.
   - Vómetros de nivel estéreo L/R en vivo.
   - Controles ajustables de saturación y wobble.
5. **Asset Matrix Y2K / Acid Graphics:**
   - Insignias de *Parental Advisory Explicit Content*, *Compact Disc Digital Audio*, *Rating R* y código de barras.
   - Marquesina de texto técnico continuo.

## 💡 Cómo Ejecutar
Simplemente abre el archivo `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge, Safari) sin necesidad de servidor local.
